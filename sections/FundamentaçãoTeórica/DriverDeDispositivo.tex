\section{Driver de Dispositivo}

Um driver de dispositivo é um software responsável por permitir a comunicação entre o \gls{so}  e um componente específico do computador.
Ele funciona como uma camada intermediária que traduz os comandos do sistema em instruções compreensíveis para o dispositivo físico, como impressoras, placas de vídeo, teclados,
discos rígidos e interfaces de rede.
