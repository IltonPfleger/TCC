\section{EPOS}

\gls{epos} \citeonline{EPOS-paper} é um \gls{rtos} orientado a objetos desenvolvido em C++ com foco em aplicações embarcadas e sistemas dedicados.
Sua arquitetura é baseada em componentes modulares, permitindo que apenas os recursos necessários para cada aplicação sejam incluídos no sistema final,
reduzindo \textit{overheads} desnecessários.

O EPOS adota o conceito de \textit{Application-Oriented Operating System}, no qual um sistema operacional é configurado de acordo com os
requisitos específicos de uma aplicação. Para isso, são utilizadas técnicas de orientação a objetos e metaprogramação em toda a base de código desse sistema.

O trabalho desenvolvido neste documento baseia-se fortemente nos princípios arquiteturais do EPOS, especialmente em sua modularidade e abstrações.
